# X-Tracker

**X-Tracker** 是一款专为 X、微博 (Weibo)、雪球 (Xueqiu)、小红书 (Xiaohongshu) 和 Substack 用户打造的高效信息聚合与监控 Chrome 扩展程序。

不同于传统的 Timeline，X-Tracker 就像您的私人情报中心，让您可以“只看想看的人，只读想读的内容”。

## 核心功能 (Core Features)

### 双视图设计 (Dual View Design)
- **Feed (动态)**：您的纯净浏览入口。按“最近浏览时间”倒序排列，点击 X 账号在插件内阅读，其他来源跳转查看。最近点击的账号会自动排在最前，方便您快速回访常用关注。
- **Lists (列表)**：您的管理中心。在这里添加、删除、编辑关注对象，并通过复选框进行批量操作（如一键打开多个选中账号）。

### 多平台支持
- **X**：支持侧栏阅读推文、双语显示与卡片导出。
- **雪球**：支持内容抓取。
- **微博 & 小红书 & Substack**：提供“一键直达”功能，点击即可快速跳转至个人主页。
- **普通网页链接**：支持添加任意网页链接（如新闻网站、博客等）。

### 智能管理
- **自定义列表**：创建跨平台的自定义关注列表。
- **别名系统**：为关注对象设置好记的备注名。
- **批量操作**：在 Lists 视图中勾选多个用户，一键批量打开。
- **数据持久化**：所有数据均存储在本地，安全可靠。

## 安装指南 (Installation)

1.  下载源代码并解压。
2.  在 Chrome 地址栏输入 `chrome://extensions/`。
3.  开启右上角的 **开发者模式**。
4.  点击 **加载已解压的扩展程序**，选择解压后的文件夹。

## 使用说明 (Usage)

1.  **添加关注**：在 **Lists** 标签页输入用户名或链接，点击 Add。
2.  **浏览**：切换到 **Feed** 标签页，点击卡片查看内容。列表按最近浏览时间排序。
3.  **批量打开**：在 **Lists** 标签页勾选多个用户，点击底部的 "Open Selected"。

## 插件内阅读 X（1.11.1）

点击动态中的 X 账号，在侧栏阅读该用户最新一条推文；向下滚动加载更早推文。上方显示原文，读取到 X 中文译文时自动显示在下方；底部翻译图标可隐藏、显示或重试获取译文。顶部问候、刷新和“动态 / 收藏 / 列表”菜单始终可见，阅读时也能直接切换页面。图片、引用内容和互动数量尽量沿用 X 的布局。

需要在同一个 Chrome 用户配置中登录 X。扩展使用不激活的临时后台标签页读取内容，完成后关闭；可读取范围受账号权限、搜索结果、限流和 X 页面结构影响。视频提供原文播放入口。

### 本地头像与动态同步

头像按用户名保存为 PNG 图片数据，写入后回读校验。动态列表、阅读页和导出卡片共用本地缓存；自动获取头像后，已显示的同账号头像立即更新，不影响其他账号和动态排序。刷新页面、重新加载同一扩展和重启浏览器后保留缓存。

正文先返回，自动头像补取作为独立后台请求进行：已有缓存、下载作者头像、补取用户主页并从页面读取。只使用与当前账号对应的头像节点或作者主页链接，忽略其他账号与引用推文中的图片。升级时清理旧版自动缓存并重新获取，保留本地上传头像及关注列表。

头像操作全部自动进行，不再显示手动获取/上传菜单。已上传的旧头像继续保留，自动读取不会覆盖。最多保存 100 个账号；超过容量时移除最早缓存。首次未获取成功且无缓存的账号暂使用首字母。

### 卡片预览与保存

点击推文底部卡片图标打开预览，关闭预览不会下载。六种样式为浅雾灰、奶油纸、冰川蓝、青竹绿、午夜蓝和纯白原文。切换边框立即重新生成预览，并记住选择。放大图标可以查看文字细节；长卡片可滚动查看。

点击“保存 PNG”后选择电脑上的保存位置。保存的图片与当前预览完全一致，宽度 1520 像素；包含头像、原文、当前显示的中文译文、图片、可读取的引用及互动数量。界面和图片中省略翻译来源标签、保存成功提示、完整链接和水印。视频不嵌入静态图片。

1.13.2 恢复旧版 Chrome 内置 Translator API：点击推文底部翻译图标，生成中文并显示在英文下方。首次使用可能需要下载语言包；接口不可用或翻译失败时显示简短错误并可重试。翻译直接使用正文，不依赖 X 网页的译文、登录状态或临时翻译标签页，不需要配置 API Key。译文保存到本地，收藏和卡片预览使用当前显示的译文，重启后可离线读取。再次点击翻译图标可收起或展开中文。旧版 Chrome 译文继续显示；上个版本存储的 X 页面译文保留在缓存，但点击图标会使用 Chrome 重新生成。此方案为浏览器内置翻译 API，并非 Google Cloud Translation。引用暂保留原文。

### 浏览缓存与收藏（1.12.0）

浏览 X 推文时，每次下滑加载的所有推文都会自动保存正文、作者、日期、引用内容及互动数量；默认只展示最新一条并不限制缓存条数。翻译生成后也保存中文译文。再次打开账号先显示最新一条本地快照，并独立更新最新推文；更新请求不阻塞本地分页。向下滚动或点击“加载”，每次追加最多 5 条。已有缓存直接分批读取，没有缓存时才请求 X。新推文与旧缓存之间存在缺口时先分批读取缺口，避免跳过内容。断网或 X 获取失败时使用已有内容。联网结果为空时仍能加载已有的更早缓存；联网结果中缺失的已浏览推文按时间顺序补回，避免跳过尚未读取的分页。

缓存直接通过动态中的账号读取，不提供独立历史标签。主导航为“动态 / 收藏 / 列表”，收藏和列表可随时直接切换。点击每条推文右侧书签可收藏或取消收藏；蓝色实心书签表示已收藏。收藏按收藏时间排列，取消后立即从收藏页移除。动态中的缓存阅读和收藏都支持下滑分页、翻译和卡片预览保存。

内容和图片保存在扩展的 IndexedDB 中；头像继续共用本地头像缓存。已成功下载的图片可离线阅读和导出；未下载成功的图片及视频仍需要网络。浏览过的推文和已下载图片持续保留，不再按 500 条或 80 MB 自动清理。扩展声明 unlimitedStorage，减少浏览器存储配额和自动回收造成的数据丢失；实际磁盘空间不足时仍可能保存失败。缓存只覆盖本版本启用后实际加载的内容，不会补回以前已经浏览但未保存的推文。

本地数据在重新加载同一扩展、刷新侧栏和重启 Chrome 后保留。原有列表导入/导出只备份账号设置，不包含推文缓存和收藏；卸载扩展会删除本地数据。

### 更新已有安装

用新版文件覆盖原扩展文件夹，在 `chrome://extensions` 中点击该扩展的重新加载按钮，关闭并重新打开侧栏，再刷新用户。必须重新加载扩展，让后台同时更新；仅刷新侧栏可能仍运行旧版后台。无需卸载，用户列表和上传头像会保留。

### X 原生译文与精简界面（1.13.0）
